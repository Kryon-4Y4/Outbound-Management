## 📋 项目简介

### 1.1 项目概述

Outbound Management System（出库管理系统）是一款基于 **B/S 架构** 的企业级仓储管理软件。系统采用浏览器即可登录，支持内外网访问、邮箱访问，支持多用户同时在线使用，提供从物料管理、产品管理到货单管理、打包作业的全流程仓储管理解决方案。

## 📦 功能模块

### 3.1 功能总览

| 模块分类 | 功能模块 | 功能说明 |
|----------|---------|----------|
| 通用功能 | 系统访问 | 系统采用 B/S 架构，使用浏览器即可登录系统，支持内外网、邮箱访问登陆，支持多用户同时在线使用 |
| | 系统安全 | 系统本地部署，数据安全保障 |
| 用户管理 | 用户管理 | 可以添加、修改、删除账号。可以对账号进行菜单功能授权 |
| 物料管理 | 物料列表 | 页面通过搜索查询物料清单，可以对物料进行新增、修改、删除、导入等操作 |
| | 新增/修改物料 | 设置物料的编码、名称、单位、打包位置 |
| 产品管理 | 产品列表 | 页面通过搜索查询产品信息，页面可以对产品进行新增、修改、删除、导入等操作 |
| | 新增/修改 | 添加产品的属性（产品条码、名称、单位、品牌、颜色等），支持选择物料清单，设置物料所需的数量 |
| 货单管理 | 货单管理 | 货单管理，可以查询货单的基础信息；打印标签：打印该货单下所有物料的标签；客柜管理：维护集装箱信息；货单导入：导入货单下的集装箱及产品信息 |
| | 货单管理→客柜管理 | 维护货单下面有多少集装箱，且每个集装箱的有多少产品，每个产品的数量 |
| | 货单管理→标签打印 | 统计该货单下每个配件所有的总数量，进行标签打印 |
| | 货单管理→打包记录 | 可以查看每个客柜的产品打包数量记录 |
| 产品打包 | 产品打包（传送带） | 打包员操作页面：选择货单后，查询货单下的货柜清单，点击对应货柜清单，对货柜清单下的产品进行扫描打包。本页面只打包配件设置为传送带打包的配件 |
| | 产品打包（封装） | 打包员操作页面：选择货单后，查询货单下的货柜清单，点击对应货柜清单，对货柜清单下的产品进行扫描打包。本页面只打包配件设置为封装打包的配件 |

### 7.2 核心表结构

```sql
-- 物料表
CREATE TABLE outbound_material (
  material_id bigint PRIMARY KEY AUTO_INCREMENT,
  material_code varchar(64) NOT NULL COMMENT '物料编码',
  material_name varchar(100) NOT NULL COMMENT '物料名称',
  unit varchar(20) COMMENT '单位',
  packing_location varchar(100) COMMENT '打包位置',
  status char(1) DEFAULT '0' COMMENT '状态',
  create_time datetime DEFAULT CURRENT_TIMESTAMP,
  update_time datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 产品表
CREATE TABLE outbound_product (
  product_id bigint PRIMARY KEY AUTO_INCREMENT,
  product_barcode varchar(64) NOT NULL COMMENT '产品条码',
  product_name varchar(100) NOT NULL COMMENT '产品名称',
  unit varchar(20) COMMENT '单位',
  brand varchar(50) COMMENT '品牌',
  color varchar(50) COMMENT '颜色',
  status char(1) DEFAULT '0',
  create_time datetime DEFAULT CURRENT_TIMESTAMP
);

-- 货单表
CREATE TABLE outbound_order (
  order_id bigint PRIMARY KEY AUTO_INCREMENT,
  order_no varchar(64) NOT NULL COMMENT '货单编号',
  customer_name varchar(100) COMMENT '客户名称',
  status char(1) DEFAULT '0' COMMENT '状态',
  create_time datetime DEFAULT CURRENT_TIMESTAMP
);

-- 打包记录表
CREATE TABLE outbound_packing_record (
  record_id bigint PRIMARY KEY AUTO_INCREMENT,
  order_id bigint NOT NULL COMMENT '货单ID',
  container_id bigint NOT NULL COMMENT '客柜ID',
  product_id bigint NOT NULL COMMENT '产品ID',
  quantity int NOT NULL COMMENT '打包数量',
  packing_type char(1) COMMENT '打包类型',
  operator_name varchar(30) COMMENT '操作人',
  packing_time datetime DEFAULT CURRENT_TIMESTAMP
);
```
